# Pool Maintenance Checklist

A single-page, static checklist for a home pool cleaning and chemical routine. Built with plain HTML/CSS/JS — no build step, no dependencies.

## What's inside

- **Monday & Friday (after sundown):** filter valve backwash cycle, skimmer basket, filter tablets, vacuuming, and a shock treatment.
- **Tuesday morning:** algicide dose.
- Safety reminders (water level, charging the vacuum, electric shock).
- Checkboxes that save automatically per browser (via `localStorage`) so you can track what's done each visit, plus a reset button.

## Usage

Open `index.html` in any browser — locally or hosted.

### Host it with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment," set Source to the `main` branch, root folder.
4. Save. Your checklist will be live at `https://yourusername.github.io/your-repo/`.
